# BrightStart Education Support

## Project Overview
A public-facing website and companion mobile app for BrightStart, a
role-based education support system connecting students, volunteers,
and programme administrators at a South African non-profit.

## Pages
- index.html – Home
- pages/about.html – About Us
- pages/programs.html – Programs
- pages/donate.html – Get Involved (volunteer/enrolment sign-up)
- pages/contact.html – Contact Us

## Technologies Used
HTML5, CSS3, JavaScript

## Folder Structure
- /pages – secondary HTML pages
- /assets/css – stylesheets
- /assets/js – scripts
- /assets/images – sitemap, wireframe, and site images
- /docs – Task 1 planning document
